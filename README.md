# LDM浏览器

轻量的安卓浏览器：给你电脑版浏览器般的体验，安装包大小约2MB。

- **应用名**：浏览器
- **包名**：`com.landamao.browser`
- **GitHub**：[https://github.com/landamao/browser](https://github.com/landamao/browser)
- **下载**： [https://github.com/landamao/browser/releases/latest/download/app-release.apk](https://github.com/landamao/browser/releases/latest/download/app-release.apk)

## 特色功能

### 1.标签页：像电脑浏览器一样摊开

标签页直接显示在网页上方，点击即切、长按管理，不用钻进二级菜单查找——这是与主流安卓浏览器最大的不同。

- **多标签浏览**：每个标签页独立加载，末尾「+」新建标签
  - **长按管理**： 长按任意标签弹出菜单
    - **重命名**：标题固定，不再跟随网页；清空重命名即恢复跟随。
    - **锁定**：关闭按钮变锁图标，防误触关掉，或**标记为重要标签页**。
    - **关闭**：关闭该标签页，长按菜单里的关闭不受锁定状态限制。
- **全部标签页列表**：点标签栏右缘 ▾ 弹出
  - 按住条目左缘的三条杠拖动即可排序
  - 点条目切换
  - 点右侧 × 关闭
- **一键隐藏标签栏**：长按右上角三个点菜单按钮，隐藏/显示标签页，近乎全屏的浏览体验
- **前进/后退跨启动恢复**：每个标签记住自己的浏览轨迹，重开应用后，后退/前进按钮仍能按原顺序翻回之前看过的页面
- **布局可调**：设置里可调换标签页与地址栏的上下位置、开启上下分布（标签页和网址栏一行贴屏幕顶、一行贴屏幕底），还可调标签页宽度

### 2.退出前保存：选择时机交给最清晰的自己

**设计哲学：把是否保存标签页交给最清晰的时候**

主流浏览器把「启动时恢复标签页」藏在设置深处，但问题是：启动那一刻，你往往已经不记得上次开了什么，上次退出时的网页状态重不重要根本无从判断——选什么都不对。

本浏览器思路相反：**退出前**决定是否保存。退出那一刻，你清楚每个标签页的状态

- 开关就在菜单里，一键切换
- 打开时：浏览全程实时存档——标签页顺序、当前标签、重命名、锁定、前进后退历史全部保留，下次启动原样恢复
- 关闭时：退出即清档，下次打开干干净净

### 3.文本编辑悬浮窗

菜单「文本编辑」打开文本编辑小浮窗，边看网页边摘抄：

- 可调节透明度，网页从面板后透出来
- 窗口外触摸穿透，可直接滑动、操作下方网页
- 内容自动保存；点击「保存」一键导出 txt
- 「提取链接」抓出正文里的网址列表，可复制、可直接访问
- 长按面板空白边缘进入调节状态，拖动边框自由调整窗口大小
- 键盘上方同样有快捷输入条

### 4.地址栏：输入更省事

- **快捷输入条**：键盘上方一排常用符号——`http://` `:` `/` `?` `.`，点击即插入，可在设置里自定义，（比如 `127.0.0.1`）、调整列数

### 4.内置下载器

点下载链接不再跳走，浏览器自己接管。设置里可选下载方式：

- **内置下载器（自研引擎，默认）**：HttpURLConnection 实现，零第三方库
  - **断点续传**：暂停/网络中断/杀进程后，从断点继续下载；续传前用 `Range` + `If-Range` 校验服务器文件没变，变了自动重下，不会拼出损坏文件
  - **并发排队**：最多 3 个同时下载，其余自动排队
  - **自动重试**：网络抖动自动退避重试；确定失败（如 404）不浪费时间
  - **实时进度**：每个条目显示进度条、百分比、速度
  - **通知栏**：下载进度与完成通知（不授权通知也不影响下载，页内照样有进度）
- **系统下载器**：交系统 DownloadManager，固定存公共「下载」目录
- **下载目录可选**：默认公共「下载」目录，也可在设置里选自定义目录（系统目录选择器）；自动带上登录 Cookie 与来源页 Referer，登录后才能下的文件、防盗链直链都能直接下
- **blob:/data: 链接同样支持**：网页前端动态生成的导出文件（报表、图片、CSV 等）从页面内存取出落盘，一样存到所选下载目录
- **下载管理**：菜单「下载管理」开列表页，实时显示下载状态与进度
  - 点条目：已完成/已保存的唤起「打开方式」选择器；已暂停/失败的点按即继续下载
  - 长按条目：暂停 / 继续 / 打开 / 复制来源链接 / 复制文件路径 / 删除
  - 顶部搜索框按文件名过滤

### 浏览体验

- **强制刷新**：Ctrl+F5 语义，清缓存重新请求，主流浏览器都没有这一项
- **在其他浏览器打开**：当前页面一键转交给系统里的其他浏览器

### 轻量

- release 压缩后约 1.9MB，浏览器 + 下载引擎共两个源文件，零第三方浏览器库

## 结构

```
app/src/main/java/com/landamao/browser/BrowserActivity.kt   # 全部浏览器界面逻辑
app/src/main/java/com/landamao/browser/LdmDownloader.kt     # 自研下载引擎(断点续传/并发/落盘/通知)
app/src/main/res/layout/activity_browser.xml                # 工具栏 + 进度条 + 标签栏 + WebView 容器
```

只依赖 `androidx.core`、`androidx.appcompat`、`com.google.android.material`(TabLayout)，零第三方浏览器库。

## 构建

需要 JDK 17 与 Android SDK。

```bash
./build.sh          # release 正式包
./build.sh debug    # debug 测试包
```

Windows 下双击 `build.bat`（默认 release），或手动 `./gradlew assembleDebug` / `assembleRelease`。

release 签名需在项目根目录放好自建的密钥库与 `keystore.properties`（常规 Android 签名配置），构建时自动应用。
